# Optional voice packs

Recordings by Nula / Attentionn, generated with ElevenLabs and edited in FL Studio. This source package prepares the folders but does not contain voice recordings. Add the recordings before distributing the voice packs.

Languages: `en` = English; `esp` = Spanish; `fr` = French; `cn` = Chinese.

Use these exact filenames in each language folder:

- `replay.wav`
- `mute.wav`
- `unmute.wav`
- `reminder.wav`
- `replay_start.wav`
- `replay_stop.wav`
- `mic_silent.wav`
- `desktop_silent.wav`
- `black_screen.wav`
- `frozen_screen.wav`

Use 16-bit PCM WAV, mono or stereo, up to 4 MiB per file. Keep the files in a permanent location, then choose each event under Tools → OBS Companion → Customize sounds → Browse → Test → Apply. Blank paths use embedded tones. Language selection does not automatically change sounds.
